## 14. Glossary   

| Term | Definition |   
| --------- | --------- |   
| Assignee | The person responsible for completing a task. |   
| Dashboard | The main screen that provides an overview of projects and tasks.|   
| Project | A collection of related tasks and activities. |     
| Task | An individual activity that must be completed. |   
| Status | The current state of a task. |   
| Priority | An indication of how urgently a task should be completed. |
