## 2. Getting started   

### 2.1 Sign in to TaskFlow   

To sign in to TaskFlow:  
1. Open your web browser.   
2. Go to the TaskFlow login page.   
3. Enter your email address.  
4. Enter your password.   
5. Click **Sign In**.   
   
>**Tip**: Select Remember me if you are using TaskFlow on a trusted device.   

#### 2.1.1 Reset your password   

If you forgot your password:  
1. On the Sign In page, click **Forgot password?**   
2. Enter your registered email address.   
3. Click **Submit**.   
4. Check your email for the password-reset link.   
5. Follow the instructions in the email to create a new password.   

### 2.2 TaskFlow dashboard   

After you sign in, the Dashboard appears.   
The dashboard contains the following sections:     
- **My Tasks** – Displays tasks assigned to you.   
- **Projects** – Displays the projects you can access.   
- **Notifications** – Displays recent activity.   
- **Calendar** – Displays upcoming deadlines.   
- **Reports** – Displays project-related reports.   

### Dashboard component   

After you sign in, the Dashboard appears.    

| Component | Description | Access |  
| :---------: | :---------: | :---------: |
| My Tasks | My Tasks | All users |
| Projects | Displays available projects | All users |  
| Notifications | Displays recent updates | All users |
| Reports | Displays project reports | Managers |  
| Administration | Manages users and settings | Administrators |



## 5. Add comments   

You can use comments to communicate with other project members.   
### 5.1 Add a comment   

1. Open the task.   
2. Scroll to the Comments section.   
3. Enter your message.   
4. Click **Post**.   

For example:  
> The first draft of the user guide is ready for review. Please add your comments by Friday.   

#### 5.1.1 Mention a team member

To notify a specific team member:     
1. Type `@`.   
2. Enter the person's name.   
3. Select the person from the list.   
4. Enter your message.   
5. Click **Post**.   

The selected user receives a notification.   

## 6.1 Supported file types   

TaskFlow supports the following file types:   
- `.pdf`   
- `.docx`   
- `.xlsx`   
- `.pptx`   
- `.png`   
- `.jpg`   
- `.txt`   
  
> **Note**: The maximum file size is 25 MB.   

## 6.2. Attach files   

To upload a file:  
1. Open a task.   
2. Select **Attachments**.   
3. Click **Upload File**.   
4. Select the file from your computer.   
5. Click **Open**.   

The file appears in the **Attachments** section.

## 7. Track task progress   

TaskFlow uses statuses to indicate the current state of a task.   
| Status | Description |   
| ------ | ------|   
| Not Started | Work has not started.|   
| In Progress | Work is currently underway. |   
| Under Review | Work has been completed and is awaiting review. |   
| Completed | The task has been completed. |   
| Blocked | Work cannot continue because of an issue or dependency. |   

## 7.1 Change the task status   

To change the status of a task:   
1. Open the task.   
2. Click the **Status** drop-down list.     
3. Select the required status.   
4. Click **Save**.   

## 8. Search for a task   

### Search procedure   
1. Click the **Search** icon.   
2. Enter a keyword or task ID.   
3. Press **Enter**.   
4. Review the search results.   
5. Select the required task.   
> Tip: Use specific keywords to narrow your search results.   

## 9. Notifications   

TaskFlow sends notifications when important events occur.   

Notifications can be triggered when:   
- You are assigned a task.   
- Someone mentions you in a comment.   
- A task assigned to you is updated.   
- A task deadline changes.   
- A project you're part of is updated.
