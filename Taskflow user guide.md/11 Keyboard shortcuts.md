## 11. Keyboard shortcuts   

TaskFlow supports several keyboard shortcuts.   
| Action | Windows | macOS |   
| --------- | --------- | --------- |   
| Search | `Ctrl+K` | `Command + K`|   
| Save | `Ctrl + S` | `Command + S` |   
|Close Window | `Esc` | `Esc` |   
| New Task | `Ctrl + N` | `Command + N` |
