## 1. Introduction   

Welcome to TaskFlow, a project management application that helps teams create, organize, assign, and track tasks.   
This guide explains how to use the basic features of TaskFlow, including:   
- Creating projects   
- Creating and assingning tasks   
- Setting task priorities   
- Adding comments and attachments   
- Tracking task progress   
- Managing team members    

If you encounter any issues while using TaskFlow, see [Troubleshooting](#10-troubleshooting).   

>**Note**: You must have a TaskFlow account before you can create or manage projects.   

### 1. 1 Intended audience   

This guide is inteded for:   
- Project managers   
- Team leads   
- Team members   
- Administrators   

### 1.2 Prerequisistes   

Before using TaskFlow, make sure that you have:   
1. A valid TaskFlow account.   
2. Access to a TaskFlow project.   
3. A supported web browser.   
4. An active internet connection.
