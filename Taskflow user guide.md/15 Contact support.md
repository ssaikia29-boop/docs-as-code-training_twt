## 15. Contact support   

If you cannot resolve an issue using this guide, contact the TaskFlow Support Team.   
**Support email**: support@example.com    
**Supoort hours**: Monday–Friday, 9:00 AM–6:00 PM IST    

When contacting support, include the following information:   

1. Your name and email address.     
2. Project or task name.   
3. Description of the issue.   
4. Steps you performed before the issue occurred.   
5. Screenshot of the error message, if applicable.
