## 10. Troubleshooting   

If you encounter an issue while using TaskFlow, try the following solutions.   

### 10.1 Unable to sign in   
**Problem**: You cannot sign in to TaskFlow.   

**Possible causes**:  

- Incorrect email address   
- Incorrect password   
- Account is locked     
- Network connectivity issue   

**Solution**:   

1. Verify that your email address is correct.   
2. Check that Caps Lock is disabled.   
3. Reset your password if necessary.     
4. Check your internet connection.     
5. Contact your administrator if the issue persists.   

## 10.2 File upload fails   

**Problem**: You receive an error when uploading a file.   

**Possible causes**:   

- File exceeds the maximum size.   
- File type is not supported.     
- Internet connection was interrupted.   
  
> **Important**: Do not repeatedly upload the same file if the application displays a server error. Contact your administrator if the problem continues.
